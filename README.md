
Trading Bot 🤖📈
Willkommen im Trading Bot-Repository! Dieses Projekt ist ein einfacher, automatisierter Trading-Bot, der speziell für die Kraken-Plattform entwickelt wurde. Der Bot ermöglicht es dir, Trades basierend auf grundlegenden Logiken auszuführen. Dieses Projekt ist noch in der Entwicklung und wird kontinuierlich erweitert.

Funktionen ✨
Automatisiertes Trading: Führe Trades basierend auf einfachen Regeln aus.

Kraken-Integration: Direkte Anbindung an die Kraken-API für Handelsausführungen.

Einfach und leicht verständlich: Der Code ist klar strukturiert und einfach zu erweitern.

Verwendung 🚀

Copy

Der Bot führt Trades basierend auf der implementierten Logik aus.

Konfiguration
Passe die config.py an, um grundlegende Einstellungen wie Handelsgröße und Handelsintervalle zu ändern.

Unterstützte Plattform 🌐
Kraken: Der Bot ist speziell für die Kraken-Plattform entwickelt.
